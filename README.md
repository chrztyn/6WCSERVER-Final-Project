# Production-ready deployment branch

Install all `npm` dependencies by using the command:
```
npm run install-all
```
on the root directory.

To start the development server, use the command:
```
npm run dev
```
on the root directory.

To start the production server, use the command:
```
npm start
```
on the root directory.

> Make sure to have your .env file as well on the root (/) directory.
